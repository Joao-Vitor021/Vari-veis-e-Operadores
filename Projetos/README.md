# Variáveis e Operadores em Java

Este projeto foi criado com o objetivo de praticar os fundamentos da linguagem Java, utilizando variáveis e operadores aritméticos.

##  O que foi praticado
- Declaração de variáveis do tipo `double`
- Operações aritméticas:
  - Soma
  - Subtração
  - Multiplicação
  - Divisão
- Saída formatada no console utilizando `System.out.printf`

##  Tecnologias
- Java

##  Como executar
1. Compile o arquivo:
   ```bash
   javac VariaveisEOperadores.java
